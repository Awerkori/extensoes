# Project Nox · Extensões de Mangá

Repositório oficial de distribuição e catálogo compilado de extensões de mangá para **Mihon**, **TachiyomiSY** e forks compatíveis.

---

## 🎯 Para quem é este repositório?

Este repositório é voltado para **leitores e usuários finais** que desejam instalar e atualizar extensões de leitura de mangás, manhwas e quadrinhos diretamente em seus aplicativos móveis.

Se você procura o **código-fonte em Kotlin** das extensões ou deseja contribuir tecnicamente com correções, acesse o repositório irmão:
➡️ [**Project Nox · Código-fonte das Extensões de Mangá**](https://github.com/Awerkori/manga-fonte-extensoes)

---

## 📲 Como Adicionar ao Mihon / TachiyomiSY

### Método 1: Adicionar Automaticamente (Recomendado)
Clique no link abaixo a partir do seu celular para abrir o instalador do aplicativo:

👉 [**Adicionar Repositório ao Aplicativo**](tachiyomi://add-repo?url=https%3A%2F%2Fraw.githubusercontent.com%2FAwerkori%2Fmanga-extensoes%2Frepo%2Findex.min.json)

---

### Método 2: Adicionar Manualmente

1. No **Mihon** ou **TachiyomiSY**, abra **Configurações** → **Navegar** → **Repositórios de extensões**.
2. Toque no botão **Adicionar** (`+`).
3. Cole a URL do catálogo moderno (Protobuf):

```
https://raw.githubusercontent.com/Awerkori/manga-extensoes/repo/index.pb
```

*(Para versões antigas ou compatibilidade estrita com JSON, utilize `https://raw.githubusercontent.com/Awerkori/manga-extensoes/repo/index.min.json`).*
